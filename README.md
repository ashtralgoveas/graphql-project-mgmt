# Project Pulse

A client and project management application built to explore GraphQL and Apollo Client. The application allows users to manage client records, create and update projects, and associate projects with their respective clients.

## Features

- **Client Management:** Create, view, update, and delete client records.
- **Project Management:** Create and update projects.
- **Client-Project Relationships:** Assign projects to existing clients and organize project information by client.
- **GraphQL API:** Use GraphQL queries and mutations to retrieve and modify application data.
- **Apollo Client Integration:** Manage GraphQL requests and integrate server data into the frontend.
